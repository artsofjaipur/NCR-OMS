Packing Scan

→ READY TO DISPATCH

Scan the AWB or Order ID on the label. The order is marked packed and flips to Ready to Dispatch — with brand, marketplace and courier shown for confirmation.

Scanner works out of the box — it types and presses Enter. Re-scanning a label is safe (shows “already packed”).

Return Sheet Upload

DAILY CSV

Upload the store's daily return report. Rows match by Order ID (reverse AWB as fallback). Re-uploading the same sheet never creates duplicates — existing returns are updated.

Return Receive Scan

→ RECEIVED

When the return box physically arrives, scan the reverse AWB or Order ID. The return is marked Received — then QC → Restock adds it back to inventory.

Only open returns (Initiated / In-Transit) match — a return can be received once.
